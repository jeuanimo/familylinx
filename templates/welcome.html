All Features

Family Space

Your private family hub. Everything — the tree, feed, chat, albums — lives inside a Family Space. You can belong to more than one (e.g. maternal and paternal sides).

How to set it up:
  1. Click New Space in the top nav
  2. Name it (e.g. "The Smith Family") and add a description
  3. Invite family members via the Invitations card
  4. Assign roles — Owner controls everything, Admins manage members, Editors update the tree, Members can post and comment, Viewers are read-only
{% if user.is_authenticated %} Create Family Space {% endif %}

Family Tree

Visual, interactive family tree with photos. Supports parent, child, spouse, grandparent, and great-grandparent relationships. Includes a D3-powered photo view.

How to set it up:
  1. Open your Family Space and click View Tree
  2. Click Add Person to create the first person
  3. Open any person card and use the relationship tiles (Parent / Child / Spouse etc.) to build connections
  4. Upload photos on each person's profile for the visual tree
  5. To import an existing tree, use GEDCOM Import (see below)

People & Relationships

Each person in the tree has their own profile: birth/death dates and places, photo, linked user account, and full relationship history.

Key actions:
  1. Link yourself: On the Family Space, click Find Me on Tree to connect your user account to your person record — your profile photo then shows on the tree
  2. Add relationships: From a person's detail page, use the relationship tile buttons (Parent, Child, Spouse, Grandparent, Great-Grandparent) or the full Relationship form for custom types
  3. Merge duplicates: Use Admin Tools → Duplicate Queue to find and merge identical records

GEDCOM Import

Import an existing family tree from Ancestry, MyHeritage, FamilySearch, or any genealogy software that exports .ged files.

How to import:
  1. Export a .ged file from your genealogy software
  2. Open your Family Space → Family Tree → Import GEDCOM
  3. Upload the file and review the import report
  4. The import is reversible — use Rollback if something looks wrong
  5. After importing, use the Duplicate Queue to clean up any repeated people

Family Feed

A private social timeline for your family. Share updates, photos, and videos. Like and comment. Tag family members. Pin important posts.

How to use it:
  1. Open your Family Space — the post box is at the top of the feed
  2. Type your update, optionally attach a photo or video
  3. Tag family tree members using the tag field
  4. Filter the feed: Entire Tree shows all posts; Immediate Family shows only your close relatives (requires linking yourself to the tree)

Photo Albums

Organised photo albums for the whole family. Upload multiple photos, write captions, tag people in the tree, and set album cover photos.

How to set it up:
  1. Open your Family Space → Photo Albums
  2. Click New Album, give it a name and description
  3. Upload photos — they're cropped and optimised automatically
  4. Tag family tree members on each photo for easy search
  5. Set a cover photo that represents the album

Messaging & Chat

Family group chat, direct messages between members, and branch chats tied to specific parts of the tree or events.

Types of conversations:
  1. Family Chat: Group chat for all members of a Family Space
  2. Direct Messages: Private 1-on-1 conversations — click the chat icon next to any member
  3. Branch Chat: Discuss a specific person's branch of the tree
  4. Event Chat: Conversation tied to a specific event
  5. Access all conversations from your Family Space → Open Messages

Events & Calendar

Plan family gatherings, reunions, and holidays. RSVP tracking, event-specific chat, and a calendar view of all upcoming dates.

How to use it:
  1. Open your Family Space → Upcoming Events → Create Event
  2. Set the date, time, location, and description
  3. Family members can RSVP with Yes / Maybe / No
  4. Each event has its own chat thread for coordination
  5. View all events on the calendar: Family Space → Events

Living Museum

Preserve family memories, stories, and milestones. Each person in the tree can have their own museum page with an auto-generated life story. Includes an AI chatbot to explore a person's history.

How to use it:
  1. Open your Family Space → Visit Museum
  2. Click Add Memory to record a story, photo, or milestone
  3. Attach memories to specific people in the tree
  4. View a person's full Life Story from their profile
  5. Use Share to create a public link for a memory (no account needed to view)
  6. Try the AI Chatbot on any person's page to ask questions about their life

Occasions & Milestones

Never miss a birthday, anniversary, or memorial. Automatic reminders pulled from your tree's birth, death, and marriage dates. Add custom milestones and send Kudos.

What's included:
  1. Birthdays: Auto-generated from each person's birth date
  2. Wedding Anniversaries: From relationship start dates
  3. In Memoriam: Annual reminders for those who have passed
  4. Kudos: Send a shout-out to celebrate achievements
  5. Custom Milestones: Record graduations, moves, career wins, etc.
  6. Time Capsules: Write a message to be opened on a future date

DNA Tools

Track DNA kit results from AncestryDNA, 23andMe, or similar. Log matches, confirm relationships, and visualise DNA connections across the tree.

How to set it up:
  1. Go to DNA in the nav → Add New Kit
  2. Enter your kit provider and ID
  3. Link the kit to a person in your family tree
  4. Add DNA matches manually and set the estimated relationship
  5. Confirm matches to attach them to the tree
  6. View the DNA Connections graph to visualise everything

Prayer & Spiritual

Share prayer requests with your family or the wider FamilyLinx community. Mark prayers as answered, write testimonies, and support each other.

How to use it:
  1. Open your Family Space → Prayer Requests
  2. Click New Request to share a prayer need
  3. Family members can click I'm Praying to show support
  4. Reply to prayers with encouraging messages
  5. When answered, mark it and write a testimony
  6. Browse the Global Prayer feed to support others beyond your family

Genealogy Discussions

A Reddit-style forum for your family to discuss genealogy questions, share research, and debate family history. Upvote, bookmark, and categorise threads.

How to use it:
  1. Open your Family Space → Genealogy Thread
  2. Click New Post to start a discussion
  3. Assign a category (Research, Stories, Questions, etc.)
  4. Members can reply, upvote, and bookmark threads
  5. Admins can moderate and manage categories

Tree Linking & Merging

Connect your family tree to another Family Space's tree — useful for blended families or when two branches have been researched separately. Optionally merge the trees together.

How to use it:
  1. Open your Family Space → Tree Linking (via Admin Tools or tree page)
  2. Search for another family space to connect to
  3. Compare the two trees to find common ancestors
  4. Propose a link — the other family's admin must approve
  5. For a full merge, use Tree Merge Request — this combines both trees permanently (requires both owners to approve)

Data Protection & Audit

Soft-delete protects against accidents. An audit log records every change. Members can request deletion of their data and admins review those requests.

What's available:
  1. Trash Bin: Deleted people and relationships go here first — restore or permanently delete
  2. Audit Log: Full history of who changed what and when
  3. Deletion Requests: Members request removal of their data; admins approve or deny

Find these under Admin Tools on your Family Space.

Members Directory & Friends

Browse all FamilyLinx users, send friend requests, message anyone directly, and see who's online.

How to use it:
  1. Click Members in the top nav to browse all users
  2. Visit a profile and send a Friend Request
  3. From your own profile, manage friends and search for users
  4. Send a direct message from any profile page or the Members list
  5. Green dot = online (active in the last 5 minutes)
